# Image Classification with CNN and AlexNet on CIFAR-10

An image classification project using Convolutional Neural Networks (CNN) and the AlexNet architecture on the CIFAR-10 dataset.

## Overview
- Building a CNN model from scratch for image classification
- Implementing the AlexNet architecture
- Training and evaluating the model on the CIFAR-10 dataset

## Files
- `Day1_2_Image_Classification_CNN_And_AlexNet_CIFAR10.ipynb` — Jupyter notebook containing the full code

## Requirements
- Python
- TensorFlow / Keras or PyTorch (depending on what's used in the code)
- NumPy, Matplotlib
